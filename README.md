# ชีวิตง่าย

แอปผู้ช่วยเรื่องประจำวัน ใช้บนมือถือได้เหมือนแอป และใช้ได้แม้ไม่มีเน็ต

หัวข้อแรกคือ **ครัวบ้านเรา**: หาเมนูจากเครื่องครัวและของในตู้เย็น จัดมื้อ ทำตามทีละขั้นพร้อมตัวจับเวลา และดูรายการซื้อของ

เปิดใช้งาน: https://kxmziii.github.io/chiwit-ngai/

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `src/app.html` | ตัวแอปทั้งหมด (หน้าตา ข้อมูลสูตรอาหาร และการทำงาน) แก้ที่ไฟล์นี้ |
| `build.sh` | สร้าง `index.html` จาก `src/app.html` |
| `index.html` | หน้าเว็บที่เปิดใช้งานจริง สร้างจาก `build.sh` ไม่ต้องแก้เอง |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอปบนมือถือ |
| `sw.js` | เก็บสำเนาแอปไว้ในเครื่อง ให้เปิดได้ตอนไม่มีเน็ต |
| `icons/` | ไอคอนของแอป |

## วิธีอัปเดต

```bash
bash build.sh
```

```bash
git add -A && git commit -m "อัปเดตแอป" && git push
```

หลัง push ประมาณ 1 นาที เว็บจะเปลี่ยนเป็นเวอร์ชันใหม่

## เพิ่มหัวข้อใหม่

ใน `src/app.html` มีรายการ `TOPICS` หัวข้อใหม่แต่ละอันต้องมี 3 ส่วน:

1. `<section id="view-...">` สำหรับแต่ละหน้าของหัวข้อ
2. ปุ่มแท็บใน `<nav class="tabs">` ที่มี `data-view` ตรงกับชื่อหน้า
3. รายการใน `TOPICS` ที่บอกชื่อ ไอคอน และหน้าของหัวข้อ

## ข้อมูลของผู้ใช้

เมนูโปรด ของในตู้เย็น และมื้อที่จัดไว้ เก็บอยู่ในเบราว์เซอร์ของเครื่องที่ใช้เท่านั้น ไม่ได้ส่งไปที่ไหน
